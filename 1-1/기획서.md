# 🎬 영화 티어 웹사이트 기획서

## 1. 사용 고객
- **타겟층:** 1020 세대 영화 팬 및 월 1회 영화관람 일반인
- **플랫폼:** PC 환경 최적화
- **기능 요구:**
  - 다른 사용자와 티어 리스트 공유 가능
  - 로그인을 통한 개인 리스트 저장
  - 가상 아이디 3개 기반 목업 로그인 (DB 미구현)

## 2. 만든 목적
- **주 목적:** 포트폴리오 제작 및 사용자 맞춤형 영화 추천
- **디자인 벤치마킹:** Letterboxd UI 차용
- **차별성:** 랜딩 페이지에서 최신 인기 영화 즉시 노출
- **부가 기능:** 영화 클릭 시 리뷰 및 토론용 코멘트창 제공
- **수익화:** 미고려

## 3. UI/UX 동작
- **추천 로직:** 로그인 → 선호 장르 선택 → 장르별 인기 영화 제안 → 별점 부여(스킵 가능)
- **티어 산정 기준 (평균 별점):**
  - S Tier: 4.1~5.0 | A Tier: 3.1~4.0
  - B Tier: 2.1~3.0 | C Tier: 0.0~2.0
- **메인 레이아웃:** 세로축(티어), 가로축(최신 인기 영화 포스터)
- **호버 효과:** 포스터 호버 시 리뷰 수 & 평점 표시
- **테마:** 다크 모드 기본 적용
- **공유 기능:** 페이지 링크 공유만 지원

## 4. 필요 자료
- **데이터 출처:** 외부 API(TMDB) 호출 + Letterboxd 순위 참고 가공 데이터
- **템플릿:** 배경 이미지 필요
- **인증:** 소셜 로그인 미연동, 가상 아이디만 사용
- **브랜드 자산:** 없음 (기본 UI 활용)

## 5. 완성 기준
- **핵심 기능:** 영화 평균 평점, 리뷰 수, 코멘트 표시
- **호환성:** Chrome, Edge, Safari
- **성능:** 랜딩 페이지 이미지 로딩 1초 이내
- **트래픽:** 동시 접속 60명, 일일 500명
- **개발 기간:** 1일

---
## 무엇을 하려고

- 본 영화를 S·A·B·C 등급으로 나누어 내 취향을 정리합니다.

## 화면과 동작

- 위에 S·A·B·C 칸, 아래에 아직 안 정한 영화 카드를 보여 줍니다.
- 카드를 누르고 등급 글자를 누르거나, 카드를 끌어 놓으면 해당 칸으로 옮겨집니다.
- 제목을 입력하고 ‘추가’를 누르면 아직 안 정한 영화에 카드가 생깁니다.
- 영화 목록과 등급 배치를 브라우저에 자동으로 저장합니다.
- ‘처음으로’를 누르면 처음 영화 목록과 배치로 돌아갑니다.

## 완성 기준

- 영화가 한 칸에만 있고, 옮긴 칸에 남습니다.
- 제목을 입력하면 새 영화 카드가 생깁니다.
- 같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다.
- 화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다.
- ‘처음으로’를 누르면 처음 영화 8개가 모두 미분류로 돌아갑니다.
- 외부 파일·로그인·서버 실행 없이 HTML 한 장으로 열립니다.
- 빈칸이나 공백만 넣으면 카드가 생기지 않고 입력 안내가 나옵니다.
