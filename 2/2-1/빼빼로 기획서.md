# [기획서] DIY 빼빼로 만들기 & 360도 인터랙티브 편지 박스 웹 앱

## 1. 기본 항목

### 1.1 대상 사용자
- 빼빼로데이를 맞아 연인, 친구, 가족, 동료 등에게 특별하고 정성 어린 모바일 빼빼로와 손글씨 메시지를 전달하고 싶은 사용자.

### 1.2 사용 목적
- 웹 브라우저 환경에서 초콜릿 코팅, 스프링클 흩뿌리기, 초코펜 드로잉 등 DIY 빼빼로 제작 인터랙션을 즐기고, 360도 입체 관람 및 개봉 연출이 가능한 손글씨 편지 박스를 만들어 타인에게 URL 링크로 공유하기 위함.

### 1.3 화면 구성과 동작

#### A. 랜딩 및 제작 화면 (4분할 부엌 배경 콘셉트)
- **화면 구조 (4분할 구조):**
  - **좌측 상단:** 중탕 초콜릿 그릇 (선택한 색상의 초콜릿이 담긴 캔버스 영역).
  - **좌측 하단:** 초콜릿 색상 선택 팔레트 (핑크, 브라운, 초록, 레드, 블루 버튼) 및 초코펜 기능 토글 버튼.
  - **우측 상단:** 스프링클 그릇 (하트, 별 형태의 스프링클 요소).
  - **우측 하단:** 빼빼로 쌩스틱.
- **주요 인터랙션 동작:**
  1. **초콜릿 색상 선택:** 좌측 하단 팔레트 버튼 클릭 시 중탕 그릇의 초콜릿 색상이 즉시 변경됨.
  2. **초콜릿 코팅:** 우측 하단 스틱을 드래그하여 좌측 상단 중탕 그릇에 딥핑(Dipping)하면 스틱에 선택된 색상의 초콜릿이 코팅된 상태로 전환됨 (별도 코팅 과정 애니메이션 없이 결과 그래픽 즉시 적용).
  3. **스프링클 흩뿌리기 연출:** 우측 상단 스프링클을 선택해 빼빼로 위로 드래그하면, 드래그 궤적과 속도에 맞춰 빼빼로 표면에 스프링클이 일정 간격으로 자연스럽게 흩뿌려짐.
  4. **초코펜 데코레이션:** 초코펜 버튼을 활성화한 후 빼빼로 위에 드래그하여 원하는 문자나 그림을 자유롭게 그릴 수 있음.

#### B. 박스 포장 및 메시지 편지 작성 화면
- 제작 완료 버튼 클릭 시 빼빼로가 선물 박스에 입력됨.
- 메시지 입력 텍스트 에어리어(Text Area)를 제공하며, 작성된 텍스트는 박스 표면에 감성적인 손글씨 폰트로 변환되어 렌더링됨.
- 완충 후 '공유하기' 버튼 클릭 시 고유 데이터가 포함된 **URL 링크 복사 기능** 제공.

#### C. 수신자 열람 화면 (URL 인터랙션)
- 전달받은 URL 접속 시 360도 회전이 가능한 빼빼로 박스 등장.
- 드래그를 통해 박스의 앞뒤 및 측면을 360도 3D 인터랙션으로 관람 가능.
- 박스를 터치/클릭하면 상자가 열리는 개봉 연출과 함께 내부의 커스텀 빼빼로와 손글씨 편지가 공개됨.

### 1.4 필요한 자료
- **이미지 및 그래픽 리소스:** 부엌 배경 조리대 그래픽, 중탕 용기 SVG/PNG, 빼빼로 쌩스틱 이미지, 별/하트 스프링클 SVG/PNG, 선물 박스 질감 및 입체 리소스.
- **폰트:** 손글씨 느낌의 라이선스 프리 웹 폰트 (예: 나눔손글씨 붓, 온글잎 폰트 등).
- **라이브러리/엔진:** React, HTML5 2D Canvas API, Canvas 2D 기반 rendering engine 또는 360도 회전 CSS3D/Canvas 조작 엔진.

### 1.5 완료 기준
- 브라우저 상에서 초콜릿 색상 변경 ➡️ 딥핑 코팅 ➡️ 스프링클 궤적 흩뿌리기 ➡️ 초코펜 드로잉 ➡️ 손글씨 편지 작성 ➡️ URL 링크 생성 ➡️ 360도 열람 및 개봉 연출까지 전 과정이 오류 없이 정상 동작해야 함.

## 2. 기능 분류

### 2.1 필수 기능
1. **React & HTML5 Canvas 기반 인터랙티브 제작 엔진**
   - 중탕 초콜릿 5색(핑크, 브라운, 초록, 레드, 블루) 컬러스와핑.
   - 빼빼로 스틱 중탕 영역 드래그 앤 드롭 코팅 완료 처리.
   - 드래그 궤적 추적 기반 스프링클 흩뿌리기 연출.
   - Canvas Context2D 기반 초코펜 자유 드로잉.
2. **손글씨 메세지 카드 생성 기능**
   - 사용자 입력 텍스트의 손글씨 폰트 박스 겉면 실시간 렌더링.
3. **URL 기반 결과물 저장 및 360도 인터랙티브 공유 기능**
   - 빼빼로 그래픽/데코 데이터 및 메시지를 URL 쿼리 파라미터(또는 Base64/JSON) 형태로 인코딩하여 생성.
   - 클립보드 URL 복사 기능.
   - 수신자용 360도 박스 회전 관람 인터랙션 및 상자 개봉 애니메이션 구현.

### 2.2 추가 기능
- 완성된 빼빼로 및 편지 박스 이미지(PNG/SVG) 다운로드 기능.
- 사운드 효과 (스프링클 뿌릴 때, 상자 열릴 때 사운드 효과음).
- 다양한 빼빼로 스틱 모양 선택 기능 (누드 빼빼로, 두꺼운 스틱 등).

## 3. 한계 및 비목표 (Out of Scope)

1. **초콜릿 굳는 실시간 액체 유체 애니메이션 미구현:** 스틱을 담글 때 초콜릿이 줄줄 흐르는 등 고난도 액체 물리 시뮬레이션은 포함하지 않으며, 딥핑 후 즉시 완성된 코팅 레이어로 전환함.
2. **서버 DB/회원가입 시스템 제외:** 별도의 회원가입이나 백엔드 서버 DB 구축 없이, 제작 데이터를 URL 인코딩/데코딩 방식으로 처리하여 순수 클라이언트 단에서 구동되도록 함.
3. **무거운 3D 게임 엔진(Unity WebGL 등) 사용 배제:** 구글 웹 브라우저 호환성 및 빠른 로딩 속도를 위해 Unity WebGL 엔진은 사용하지 않으며, HTML5 Canvas와 Lightweight Web 2D/3D 연출 기술로 대체함.

## 4. 검증 방법

- **브라우저 드래그 및 URL 공유 시나리오 테스트:**
  1. Chrome 및 Mobile Safari 환경에서 랜딩 페이지 진입 후 4분할 화면 요소들이 정상적으로 동작하는지 확인.
  2. 스틱 코팅 ➡️ 스프링클 흩뿌리기 ➡️ 초코펜 그리기 ➡️ 편지 작성이 단절 없이 수행되는지 확인.
  3. 생성된 공유 URL을 복사하여 새 창(또는 모바일 브라우저)에서 열었을 때, 상자가 360도 회전되고 클릭 시 상자가 열리며 본인이 꾸민 빼빼로와 손글씨 메시지가 정확히 재현되는지 검증.
