## 🛠️ 주요 개발 특징
* **선택 모델:** Google Gemini
* **주요 작업 내용:** 
  * 4분할 브라우저 배경 DIY 빼빼로 제작 화면 구현
  * 초콜릿 코팅, 스프링클 흩뿌리기, 초코펜 드로잉 기능 Canvas 연동
  * URL 기반 360도 박스 관람 및 손글씨 편지 데이터 복원 버그 수정 (버그픽스 완료)

  ### 1. 수정 내용과 근거 3건 기록

#### [수정 건 1] 초코펜 입체감 및 외각 드롭 텍스처 미흡 수정
- **발견한 문제**
  - **테스트 내용:** 초코펜 활성화 후 빼빼로 스틱 및 바깥 영역에 드래그 드로잉 수행.
  - **예상 결과:** 입체적인 초콜릿 튜브 질감이 표현되고, 스틱 외각에서는 중력으로 바닥에 뚝뚝 떨어져 튀는 모션이 나타남.
  - **실제 결과:** 2D 평면선 형태로만 단순하게 그려졌으며 스틱 외각 반응이 없음.
- **AI에게 전달한 요청:** "초코펜에 음영 넣어줘. 너무 그냥 그림 그린 것 같아. 스틱 외의 부분에선 드랍되는 모션도 표현해줘."
- **수정 후 테스트 결과:** 
  - **설계/구조 변경:** Canvas Stroke 렌더링을 3단 레이어 구조(하단 반투명 Drop Shadow + 중앙 Base Color + 상단 Glossy Highlight)로 확장하고, 영역 외 좌표 탐지 시 Drop Physics(중력 가속도 및 투명도 감쇠) 입자 생성 루프 추가.
  - **테스트:** 초코펜 선에 볼륨감이 부여되고 스틱 외각 드래그 시 물방울/스프링클 입자가 하단으로 떨어지는 낙하 애니메이션 정상 작동 확인.
- **수정 이유:** 초코펜의 입체감과 물리적 피드백이 부족하면 사용자가 DIY 연출 시 실물 초콜릿 튜브나 스프링클을 직접 다루는 듯한 몰입감과 재미를 느끼기 어렵습니다.

#### [수정 건 2] 로컬 브라우저 환경 실행 불가능 및 클립보드 복사 에러
- **발견한 문제**
  - **테스트 내용:** 다운로드한 HTML 파일을 개발 서버 없이 파일(file://)로 더블 클릭 실행 및 공유 링크 복사 버튼 클릭.
  - **예상 결과:** 브라우저에서 화면이 정상 렌더링되고 공유 링크가 클립보드에 복사됨.
  - **실제 결과:** React JSX 빌드 환경 미비로 화면이 켜지지 않거나, iframe 보안 정책으로 인해 `navigator.clipboard.writeText` 호출 시 에러 발생.
- **AI에게 전달한 요청:** "html로 열어도 되게 해줘."
- **수정 후 테스트 결과:** 
  - **설계/구조 변경:** Babel Standalone 및 CDN 기반 UMD React 브라우저 런타임 탑재 단일 static HTML 구조로 변환. 클립보드 기능에 `document.execCommand('copy')` 임시 textarea Fallback 로직 추가.
  - **테스트:** 별도 서버 설치 없이 `index.html` 더블 클릭만으로 바로 실행되며, 보안 제약 환경에서도 공유 URL 복사 정상 동작 확인.
- **수정 이유:** 백엔드나 빌드 도구 없이 단일 파일로 동작해야 하는 기획 조건(Static Web App)을 충족하지 못하면, 전달받은 수신자나 사용자가 웹 앱을 실행하거나 링크를 공유할 수 없는 치명적인 불편이 생깁니다.

#### [수정 건 3] 초코펜과 스프링클 간 렌더링 레이어 순서 역전 현상
- **발견한 문제**
  - **테스트 내용:** 초코펜으로 먼저 글씨/그림을 그린 후 그 위에 스프링클을 뿌림.
  - **예상 결과:** 작업 순서에 따라 초코펜 선 위에 스프링클 입자가 위에 쌓임.
  - **실제 결과:** 초코펜을 먼저 그리고 스프링클을 나중에 뿌려도 항상 초코펜 선이 스프링클보다 위 레이어로 그려짐.
- **AI에게 전달한 요청:** "스프링클을 초코펜 이후에 적으면, 초코펜 위에 스프링클이 올라가도록 해."
- **수정 후 테스트 결과:** 
  - **설계/구조 변경:** 기존의 별도 분리된 배열 상태(`sprinklesList`, `penPaths`)를 하나의 통합 타임라인 큐(`decorationsList: Array<{itemType, data}>`) 구조로 일원화하여 배열의 삽입 순서대로 Canvas에 순차 렌더링하도록 변경.
  - **테스트:** 초코펜 작성 후 스프링클을 뿌리면 해당 영역 위에 스프링클이 상위 레이어로 올바르게 덮여 그려짐 확인.
- **수정 이유:** 실제 작업 순서와 화면 표현 순서가 다르면 사용자가 의도한 시각적 장식 레이어가 꼬여 원하는 디자인으로 빼빼로를 꾸밀 수 없게 됩니다.
