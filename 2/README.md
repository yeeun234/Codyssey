# 🍫 DIY 빼빼로 만들기 웹사이트 프로젝트

본 프로젝트는 AI와의 대화를 통해 기획서를 작성하고 웹사이트를 구현한 기록입니다. Gemini와 ChatGPT 두 모델을 비교 검토한 뒤, **Gemini로 제작된 최종 버전**(버그픽스 포함)을 채택하여 프로젝트를 완성했습니다.
