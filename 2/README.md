## 🛠️ 주요 개발 특징
* **선택 모델:** Google Gemini
* **주요 작업 내용:** 
  * 4분할 브라우저 배경 DIY 빼빼로 제작 화면 구현
  * 초콜릿 코팅, 스프링클 흩뿌리기, 초코펜 드로잉 기능 Canvas 연동
  * URL 기반 360도 박스 관람 및 손글씨 편지 데이터 복원 버그 수정 (버그픽스 완료)

  ### 1. 수정 내용과 근거 3건 기록

#### [수정 건 1] 초코펜 입체감 및 외각 드롭 텍스처 미흡 수정
- **발견한 문제**
  - **테스트 내용:** 초코펜 활성화 후 빼빼로 스틱 및 바깥 영역에 드래그 드로잉 수행.
  - **예상 결과:** 입체적인 초콜릿 튜브 질감이 표현되고, 스틱 외각에서는 중력으로 바닥에 뚝뚝 떨어져 튀는 모션이 나타남.
  - **실제 결과:** 2D 평면선 형태로만 단순하게 그려졌으며 스틱 외각 반응이 없음.
- **AI에게 전달한 요청:** "초코펜에 음영 넣어줘. 너무 그냥 그림 그린 것 같아. 스틱 외의 부분에선 드랍되는 모션도 표현해줘."
- **수정 후 테스트 결과:** 
  - **설계/구조 변경:** Canvas Stroke 렌더링을 3단 레이어 구조(하단 반투명 Drop Shadow + 중앙 Base Color + 상단 Glossy Highlight)로 확장하고, 영역 외 좌표 탐지 시 Drop Physics(중력 가속도 및 투명도 감쇠) 입자 생성 루프 추가.
  - **테스트:** 초코펜 선에 볼륨감이 부여되고 스틱 외각 드래그 시 물방울/스프링클 입자가 하단으로 떨어지는 낙하 애니메이션 정상 작동 확인.
- **수정 이유:** 초코펜의 입체감과 물리적 피드백이 부족하면 사용자가 DIY 연출 시 실물 초콜릿 튜브나 스프링클을 직접 다루는 듯한 몰입감과 재미를 느끼기 어렵습니다.

#### [수정 건 2] 로컬 브라우저 환경 실행 불가능 및 클립보드 복사 에러
- **발견한 문제**
  - **테스트 내용:** 다운로드한 HTML 파일을 개발 서버 없이 파일(file://)로 더블 클릭 실행 및 공유 링크 복사 버튼 클릭.
  - **예상 결과:** 브라우저에서 화면이 정상 렌더링되고 공유 링크가 클립보드에 복사됨.
  - **실제 결과:** React JSX 빌드 환경 미비로 화면이 켜지지 않거나, iframe 보안 정책으로 인해 `navigator.clipboard.writeText` 호출 시 에러 발생.
- **AI에게 전달한 요청:** "html로 열어도 되게 해줘."
- **수정 후 테스트 결과:** 
  - **설계/구조 변경:** Babel Standalone 및 CDN 기반 UMD React 브라우저 런타임 탑재 단일 static HTML 구조로 변환. 클립보드 기능에 `document.execCommand('copy')` 임시 textarea Fallback 로직 추가.
  - **테스트:** 별도 서버 설치 없이 `index.html` 더블 클릭만으로 바로 실행되며, 보안 제약 환경에서도 공유 URL 복사 정상 동작 확인.
- **수정 이유:** 백엔드나 빌드 도구 없이 단일 파일로 동작해야 하는 기획 조건(Static Web App)을 충족하지 못하면, 전달받은 수신자나 사용자가 웹 앱을 실행하거나 링크를 공유할 수 없는 치명적인 불편이 생깁니다.

#### [수정 건 3] 초코펜과 스프링클 간 렌더링 레이어 순서 역전 현상
- **발견한 문제**
  - **테스트 내용:** 초코펜으로 먼저 글씨/그림을 그린 후 그 위에 스프링클을 뿌림.
  - **예상 결과:** 작업 순서에 따라 초코펜 선 위에 스프링클 입자가 위에 쌓임.
  - **실제 결과:** 초코펜을 먼저 그리고 스프링클을 나중에 뿌려도 항상 초코펜 선이 스프링클보다 위 레이어로 그려짐.
- **AI에게 전달한 요청:** "스프링클을 초코펜 이후에 적으면, 초코펜 위에 스프링클이 올라가도록 해."
- **수정 후 테스트 결과:** 
  - **설계/구조 변경:** 기존의 별도 분리된 배열 상태(`sprinklesList`, `penPaths`)를 하나의 통합 타임라인 큐(`decorationsList: Array<{itemType, data}>`) 구조로 일원화하여 배열의 삽입 순서대로 Canvas에 순차 렌더링하도록 변경.
  - **테스트:** 초코펜 작성 후 스프링클을 뿌리면 해당 영역 위에 스프링클이 상위 레이어로 올바르게 덮여 그려짐 확인.
- **수정 이유:** 실제 작업 순서와 화면 표현 순서가 다르면 사용자가 의도한 시각적 장식 레이어가 꼬여 원하는 디자인으로 빼빼로를 꾸밀 수 없게 됩니다.

  ### 2. 테스터 피드백 기반 추가 수정 내용과 근거 3건 기록

#### [수정 건 4] 작업 실행 취소(Undo) 기능 부재 개선
- **발견한 문제**
  - **테스트 내용:** 스프링클 흩뿌리기나 초코펜 드로잉 중 실수했을 때 직전 작업만 취소하기 위해 버튼을 찾음.
  - **예상 결과:** 방금 수행한 작업(한 획 또는 한 번 드래그하여 뿌린 스프링클 묶음)만 한 단계 전으로 되돌릴 수 있음.
  - **실제 결과:** 전체 '초기화' 버튼만 존재하여 실수할 경우 처음부터 다시 만들어야 함.
- **AI에게 전달한 요청:** "1. 한단계 전으로 롤백하는 기능을 만들어달라"
- **수정 후 테스트 결과:**
  - **설계/구조 변경:** 드래그 시작(PointerDown) 시점마다 고유 작업 단위 식별자(`actionId`)를 발급하여 장식 요소(`decorationsList`)에 태깅하고, `handleUndo` 호출 시 마지막 `actionId`와 일치하는 요소 묶음 또는 코팅 상태를 순차적으로 롤백하도록 개선.
  - **테스트:** '한 단계 전으로' 및 '되돌리기' 버튼 클릭 시 직전 초코펜 획이나 스프링클 묶음, 코팅 단계가 정확히 한 단계씩 복구됨을 확인.
- **수정 이유:** 데코레이션 도중 작은 실수 하나로 모든 작업을 초기화해야 한다면 사용자의 피로도가 높아지고 자유로운 꾸미기 시도를 주저하게 됩니다.

#### [수정 건 5] 초코펜 및 화이트 생크림 튜브 질감(흐름·음영) 개선
- **발견한 문제**
  - **테스트 내용:** 초코펜(특히 흰색 색상)을 선택하여 빼빼로 표면에 글씨와 선을 그림.
  - **예상 결과:** 녹은 초콜릿이나 생크림처럼 속도감에 따라 굵기가 변하며 미세하게 흘러내리고, 흰색 크림도 입체적인 음영이 표현됨.
  - **실제 결과:** 일반 펜으로 선을 그은 듯 굵기가 일정해 흐르는 느낌이 없으며, 흰색은 음영이 약해 평면적이고 생크림 같지 않음.
- **AI에게 전달한 요청:** "2. 초코펜이 너무 글씨써지듯 써지고, 초코처럼 흐르는 느낌이 없다. 그리고 흰색은 음영도 별로 없고 크림같지 않다"
- **수정 후 테스트 결과:**
  - **설계/구조 변경:** 포인터 이동 거리 기반의 가변 선 굵기 알고리즘(느리게 움직이면 두껍게 뭉치고 빠르게 그으면 얇아짐)과 끝점·정체 구간의 미세 흘러내림 방울(`drips`) 렌더링 추가. 흰색(`#FFFFFF`) 선택 시 따뜻한 아이보리 크림 베이스(`#FFFDF7`), 베이지 윤곽선 및 브라운 톤 그림자 레이어를 다층 적용하여 몽글몽글한 생크림 질감 구현.
  - **테스트:** 천천히 그리거나 붓을 뗄 때 자연스러운 초코 방울이 맺히고, 흰색 크림 선에도 풍부한 입체 음영과 광택이 표현됨을 확인.
- **수정 이유:** 초코펜이 단순한 디지털 펜선처럼 보이면 베이킹 DIY 특유의 먹음직스럽고 아기자기한 감성이 반감되므로 실제 제과 데코레이션에 가까운 시각적 질감이 필요합니다.

#### [수정 건 6] 포장 및 링크 생성 화면에서 빼빼로 이미지 저장 불가 버그 수정
- **발견한 문제**
  - **테스트 내용:** '완성하기 & 포장' 화면으로 이동하여 링크를 생성한 뒤 '빼빼로 이미지 저장' 버튼을 클릭함.
  - **예상 결과:** 완성된 커스텀 빼빼로 이미지(PNG)가 사용자 기기에 즉시 다운로드됨.
  - **실제 결과:** 버튼을 눌러도 아무런 반응이 없으며 이미지 파일이 저장되지 않음.
- **AI에게 전달한 요청:** "3. 마지막으로 링크 전송 후에 빼빼로 이미지 저장이 안된다. 버튼에 연결된 함수 다시 체크해줘"
- **수정 후 테스트 결과:**
  - **설계/구조 변경:** 화면 모드(`PACKAGING`) 전환 시 DIY 작업대의 `<canvas>`가 언마운트되어 `peperoCanvasRef.current`가 `null`을 참조하던 구조적 원인을 해결하기 위해, Canvas 그리기 로직을 순수 함수(`drawPeperoToContext`)로 분리하고 저장 시 독립된 오프스크린 캔버스(Offscreen Canvas)를 동적 생성해 PNG로 추출하도록 재설계.
  - **테스트:** 포장 화면 전환 및 공유 링크 복사 이후에도 '빼빼로 이미지 저장' 버튼 클릭 시 크림색 카드 배경이 포함된 고화질 PNG 파일이 정상 다운로드됨을 확인.
- **수정 이유:** 기획서 필수 완료 기준(커스텀 빼빼로 완성본 PNG 다운로드)이 동작하지 않으면 사용자가 자신이 만든 결과물을 이미지로 소장하거나 메신저 등으로 공유할 수 없습니다.
