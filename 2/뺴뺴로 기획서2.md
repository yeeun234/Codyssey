# [기획서] DIY 빼빼로 만들기 & 360도 인터랙티브 편지 박스 웹 앱

## 1. 기본 항목

### 1.1 대상 사용자
* 빼빼로데이를 맞아 연인, 친구, 가족, 동료 등에게 특별하고 정성 어린 모바일 빼빼로와 손글씨 메시지를 전달하고 싶은 사용자.

### 1.2 사용 목적
* 별도의 회원가입이나 백엔드 서버 없이 브라우저 환경에서 초콜릿 코팅, 스프링클 흩뿌리기, 초코펜 드로잉 등 DIY 빼빼로 제작 인터랙션을 즐기고, 360도 입체 관람 및 개봉 연출이 가능한 손글씨 편지 박스를 만들어 타인에게 URL 링크로 공유하거나 이미지로 저장하기 위함.

### 1.3 화면 구성과 동작

#### A. 랜딩 및 제작 화면 (4분할 부엌 배경 콘셉트)
* **화면 구조 (4분할 구조):**
  * **좌측 상단:** 중탕 초콜릿 그릇 (선택한 색상의 초콜릿이 담긴 캔버스 영역).
  * **좌측 하단:** 초콜릿 색상 선택 팔레트 (핑크, 브라운, 초록, 레드, 블루 버튼) 및 초코펜 기능 토글 버튼.
  * **우측 상단:** 스프링클 그릇 (하트, 별 형태의 스프링클 요소).
  * **우측 하단:** 빼빼로 쌩스틱.
* **주요 인터랙션 동작:**
  1. **초콜릿 색상 선택:** 좌측 하단 팔레트 버튼 클릭 시 중탕 그릇의 초콜릿 색상이 즉시 변경된다.
  2. **초콜릿 코팅:** 우측 하단 스틱을 드래그하여 좌측 상단 중탕 그릇 캔버스 영역 내부로 이동시키면, 스틱에 현재 선택된 초콜릿 색상이 적용된 코팅 그래픽으로 즉시 변경된다.
  3. **스프링클 흩뿌리기:** 우측 상단 스프링클을 선택하여 빼빼로 위로 드래그하면, 마우스/터치의 이동 궤적을 따라 일정 간격으로 스프링클 입자가 자연스럽게 생성 및 배치된다.
  4. **초코펜 데코레이션:** 초코펜 버튼이 활성화된 상태에서 빼빼로 표면 영역에 드래그하면 선택된 색상의 선(손글씨/그림)이 실시간으로 그려진다.

#### B. 박스 포장 및 메시지 편지 작성 화면
* '완성하기' 버튼 클릭 시 완성된 빼빼로가 기프트 박스 내부로 전환 저장된다.
* 메시지 입력 텍스트 에어리어(Text Area)에 글자를 입력하면, 박스 표면에 감성적인 손글씨 폰트로 실시간 변환되어 렌더링된다.
* '공유 링크 복사' 버튼을 누르면 인코딩된 선물 데이터가 포함된 URL이 클립보드에 복사된다.
* '이미지 저장' 버튼을 누르면 박스 외관 껍데기 및 내부 빼빼로 완성본을 이미지 파일(PNG)로 즉시 다운로드한다.

#### C. 수신자 열람 화면 (URL 인터랙션)
* 공유받은 URL로 접속 시 360도 회전이 가능한 빼빼로 기프트 박스가 등장한다.
* 마우스/손가락 드래그를 통해 박스의 전후좌우를 360도 회전하며 관람할 수 있다.
* 박스 또는 '상자 열기' 버튼을 클릭하면 박스가 열리는 개봉 애니메이션과 함께 내부에 담긴 커스텀 빼빼로와 작성된 손글씨 편지가 노출된다.

### 1.4 필요한 자료
* **이미지 및 그래픽 리소스:** 부엌 배경 조리대 그래픽, 중탕 용기 SVG/PNG, 빼빼로 쌩스틱 및 색상별 코팅 스틱 리소스, 별/하트 스프링클 그래픽, 360도 회전용 선물 박스 입체 리소스.
* **폰트:** 라이선스 프리 웹 폰트 (예: 나눔손글씨 붓 등 손글씨 서체).
* **개발 라이브러리:** React, HTML5 2D Canvas API (외부 백엔드 서버나 DB 미사용).

### 1.5 구체적 완료 기준 (기대 결과 및 필수상태)

1. **독립 실행 조건 (외부 의존성 제외):** 별도의 회원가입, 로그인, 외부 백엔드 DB 서버, API 키 없이 단일 브라우저 환경(Static Web App)에서 완벽히 실행되어야 한다.
2. **초콜릿 딥핑 코팅:** 스틱 개체를 중탕 그릇 영역 내부로 드래그 앤 드롭하면, 스틱 표면에 현재 선택된 초콜릿 색상이 적용된 텍스트/이미지로 즉시 반영된다.
3. **스프링클 드래그 흩뿌리기:** 스프링클을 드래그하여 움직인 궤적 좌표를 따라 일정 간격으로 스프링클 입자가 빼빼로 표면에 연속 배치된다.
4. **초코펜 드로잉:** 초코펜 활성화 상태에서 빼빼로 위를 드래그하면 자유로운 궤적의 초콜릿 선이 캔버스에 실시간으로 그려진다.
5. **손글씨 렌더링:** 텍스트 에어리어에 문자를 입력하고 저장하면 박스 표면에 손글씨 폰트로 텍스트가 변환되어 나타난다.
6. **이미지 저장 기능:** 다운로드 버튼 클릭 시 (1) 박스 외관 껍데기 이미지와 (2) 내부 빼빼로 완성본 이미지가 PNG 파일 형태로 사용자 기기에 즉시 저장된다.
7. **URL 360도 관람 및 개봉:** 복사된 공유 URL로 접속 시 박스가 360도 드래그 회전하며, 클릭 시 상자가 열리면서 본래 작성자가 만든 빼빼로와 편지가 100% 동일하게 재현된다.

## 2. 기능 분류

### 2.1 필수 기능
1. **React & HTML5 Canvas 기반 인터랙티브 제작 엔진**
   * 중탕 초콜릿 5색 (핑크, 브라운, 초록, 레드, 블루) 컬러스와핑.
   * 빼빼로 스틱 중탕 영역 드래그 앤 드롭 코팅 완료 처리.
   * 드래그 궤적 추적 기반 스프링클 연속 흩뿌리기 연출.
   * Canvas Context2D 기반 초코펜 자유 드로잉.
2. **손글씨 메세지 카드 및 이미지 다운로드 기능**
   * 사용자 입력 텍스트의 손글씨 폰트 박스 겉면 실시간 렌더링.
   * 완성된 박스 외관 껍데기 및 내부 빼빼로 PNG 이미지 다운로드 기능.
3. **URL 기반 데이터 전달 및 360도 인터랙티브 공유 기능**
   * 데이터(색상, 스프링클 궤적, 드로잉, 텍스트)의 URL 쿼리 파라미터(Base64/JSON) 인코딩 및 클립보드 복사.
   * 수신자 화면 360도 박스 드래그 회전 및 상자 개봉 애니메이션 연출.

### 2.2 추가 기능 (금번 구현 제외 및 후순위)
* 사운드 효과음 (초콜릿 묻힐 때, 스프링클 뿌릴 때, 상자 열릴 때 Sound Effect).
* 다중 빼빼로 (한 상자 안에 여러 개의 빼빼로를 담는 기능).
* 3D 유체 흐름 실시간 애니메이션.

## 3. 한계 및 비목표 (Out of Scope)

1. **실시간 유체/액체 물리 시뮬레이션 미구현:** 초콜릿을 묻힐 때 뚝뚝 떨어지거나 흐르는 고난도 물리 시뮬레이션을 구현하지 않으며, 중탕 그릇 진입 즉시 코팅된 정적 그래픽 레이어로 전환한다.
2. **서버 기반 사용자 데이터베이스 및 회원가입 미지원:** 로그인 및 서버 DB 저장을 지원하지 않으며, 오직 URL 파라미터 인코딩/데코딩 방식의 순수 클라이언트 단 상태 복원만을 지원한다.
3. **중복/다중 빼빼로 제작 미지원:** 한 번에 단 1개의 빼빼로만 제작하여 상자에 포장할 수 있으며, 여러 개를 제작하여 한 박스에 넣는 기능은 이번 범위에서 제외한다.

## 4. 검증 방법 (1가지)

* **URL 데이터 복원 및 수신자 화면 일치성 검증:**
  * **비교 대상:** 작성자가 제작 시 선택한 '초콜릿 색상', '스프링클 궤적 좌표', '초코펜 드로잉 데이터', '입력한 편지 텍스트' vs 공유 URL 접속 후 수신자 화면에 복원된 데이터.
  * **검증 절차:**
    1. 랜딩 페이지에서 초콜릿 색상(예: 핑크)을 선택하고 스틱을 담가 코팅한다.
    2. 특정 궤적으로 스프링클을 뿌리고 초코펜으로 글씨를 그린 후 편지 텍스트를 입력한다.
    3. '공유 링크 복사' 버튼을 눌러 생성된 URL을 시크릿 창 또는 타 브라우저에 붙여넣는다.
    4. 360도 박스를 회전시키고 상자를 열었을 때 노출되는 (1) 박스 표면 손글씨 텍스트, (2) 빼빼로 초콜릿 색상, (3) 스프링클 위치 및 초코펜 드로잉이 원래 작성한 결과와 100% 일치하는지 비교 검증한다.
