# 실행 로그

## 작업 기록
- 과업 정의: 고객 상담 채팅 내역에서 확정된 예약 정보 추출을 반복 과업으로 정하고 타겟 사용자와 입·출력 규격을 문장으로 작성함.
- 모델 3종 비교: Claude Sonnet 5.5, GPT-6, Gemini 웹 자동 모드에 같은 프롬프트와 상담 대화를 넣고 4개 기준으로 점수와 근거를 정리함.
- 모델 선정: 연도 미안내와 구체적 도입 문의 내용 누락까지 짚어낸 Claude Sonnet 5.5를 최종 모델로 선택함.
- 페르소나 및 프롬프트 작성: 예약 정리 비서 페르소나 6요소, 3단계 추론 지침, Few-shot 예시 3건, 입력 템플릿을 작성함.
- 16턴 대화 및 반복 확인: 선정 모델에 시스템 프롬프트를 적용해 16턴 대화를 진행하며 동일 입력 2회 반복과 중간 조건 변경(이서연, 11월 27일 Google Meet)을 수행함.
- 환각 검증 및 프롬프트 v2 수정: 검증 질문 5개에 Pass/Fail을 판정하고 Turn 16의 형식 이탈 지점을 표시한 뒤 v2 프롬프트를 작성함.

## 대화 전문
- **검증 표시 요약:** 전체 16턴에서 환각과 문맥 끊김은 나타나지 않았다. Turn 16에서 `[예시 3]`의 되묻기 문장 외에 `확인된 내용` 줄이 덧붙은 지점만 `[형식 이탈]`로 표시했다.

User: 너는 '예약 정리 비서'다. 고객 상담 대화에서 확정된 일정 정보만 추출해 사실대로 정리하는 실무 보조다.
불필요한 인사말 없이 짧고 사실만 적는 개조식 문장만 사용한다.
대화에 명시되지 않은 고객명, 날짜, 시간, 연락처, 회의 링크는 절대 추측하거나 만들어 쓰지 말고 '미확인'으로 표기한다.
사실 정확도와 누락 정보 표시가 문장 다듬기보다 항상 우선한다.
