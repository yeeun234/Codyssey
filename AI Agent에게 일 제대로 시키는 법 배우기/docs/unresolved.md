# 미해결 기록

## [미해결 1] 시간대(PST/KST 등)가 명시된 상담에서 기준 시간대 혼동 없이 예약 시간 추출
- **시도한 프롬프트:**
  아래 상담 대화에서 확정된 예약 정보를 6줄 형식으로 정리해 줘. 시간대가 다르면 임의로 변환하지 말고 대화에 적힌 시간대 기준 그대로 적어 줘.
  [상담 대화]
  고객: 미국 서부 시간(PST) 기준으로 내일 오전 10시에 미팅 가능할까요?
  상담원: 네, 내일 오전 10시(PST)로 잡아드리겠습니다.

- **막힌 이유:**
  대화 안에 시간대(PST) 표기가 들어오면 프롬프트에서 임의 변환을 금지해도 다른 시간대와 섞어 적거나 시간대 표기를 생략하는 등 출력이 흔들렸다. 프롬프트를 여러 번 고쳐도 시간대 표기와 해석이 일관되지 않아 미해결 과업으로 남긴다.

## [미해결 2] 취소·보류·가예약이 섞인 대화에서 '확정된 일정'만 정확히 골라내기
- **시도한 프롬프트:**
  아래 상담 대화에서 실제로 확정된 예약만 뽑아 6줄 형식으로 정리해 줘. 취소되었거나 아직 확정되지 않은 가예약·보류 일정은 제외해 줘.
  [상담 대화]
  고객: 기존 11월 24일 오후 2시 예약은 취소해 주세요. 대신 11월 27일 오후 4시는 아직 확정은 아니고 일단 잡아만 둘 수 있을까요?
  상담원: 네, 11월 24일 건은 취소 처리했고 11월 27일 오후 4시는 가예약 상태로만 두겠습니다. 확정되면 다시 말씀해 주세요.

- **막힌 이유:**
  '가예약'이나 '잡아만 둔 상태'처럼 확정과 미확정의 경계가 애매한 표현이 들어가면, 확정된 일정이 없는데도 가예약 일정을 확정 예약처럼 채워 넣는 경우가 반복됐다. 지시문을 바꿔도 가예약 상태를 일관되게 걸러내지 못해 미해결로 기록한다.
