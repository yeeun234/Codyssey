# 미해결 기록

## [미해결 1] 여러 사람이 참여해 일정이 오가는 단체 채팅방의 최종 확정 일정 추출
- **시도한 프롬프트:**
  아래 4명이 참여한 단체 채팅방 대화에서 최종 확정된 회의 일정을 1건만 추출해 6줄 형식으로 정리해 줘.
  [대화]
  A: 다음 주 화요일 2시 어떠세요? / B: 저는 화요일 2시는 어렵고 수요일 오전 10시 가능합니다. / C: 수요일 오전 10시 좋아요. / A: 아 죄송해요 수요일 오전도 외근이네요. 목요일 4시는요? / B: 목요일 4시 OK! / C: (이모지 👍)

- **막힌 이유:**
  참여자가 여럿이고 일부가 이모지나 짧은 반응으로 답할 때 최종 합의 여부를 일관되게 판별하는 것이 까다로웠다. 프롬프트 지시만으로는 다자간 대화의 확정 기준을 안정적으로 고정하기 어려워 미해결 과업으로 남긴다.

## [미해결 2] 기준 날짜 정보 없이 대화 속 '차주 수요일' 같은 상대적 표현을 정확한 날짜로 변환
- **시도한 프롬프트:**
  상담 대화에 나온 "차주 수요일 오후 3시"를 정확한 월/일 날짜로 변환해서 예약 날짜 항목에 적어 줘. 추측하지 말고 정확한 날짜만 적어 줘.

- **막힌 이유:**
  대화 본문에 기준 날짜가 적혀 있지 않으면 어느 시점을 기준으로 '차주'를 계산해야 하는지 알 수 없어 정확도를 보장하기 어려웠다. 프롬프트만으로는 기준 시점 부재 문제를 해결할 수 없어 미해결 과업으로 남긴다.
